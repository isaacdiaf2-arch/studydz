## Study DZ — منصة تعليمية سحابية جزائرية (SaaS متعدد المؤسسات)

المشروع كبير جدًا، لذلك سأبنيه على مراحل متتابعة، وكل مرحلة تُسلَّم عاملة بالكامل باللغة العربية (RTL) ومتجاوبة 100% مع الهواتف والأجهزة اللوحية والحواسيب.

### المرحلة 1 — الهوية البصرية + الواجهة العمومية
- نظام تصميم عربي كامل (خطوط عربية، ألوان المنصة، اتجاه RTL) داخل ملف التصميم المركزي.
- الصفحة الرئيسية: تعريف بالمنصة، كيف تعمل، فوائد المؤسسات، شهادات، دعوة للتسجيل.
- صفحة الأسعار: الباقة الأساسية 7,000 دج/سنة (أساتذة وطلاب وأقسام غير محدودة).
- صفحة تسجيل مؤسسة جديدة (معلومات المؤسسة + معلومات المدير).
- صفحة الاشتراك والدفع عبر CCP: المبلغ، معلومات الحساب (ishak diaf — CCP 0042451103 — المفتاح 65)، التنبيه بكتابة اسم المؤسسة على الوصل، رفع صورة/PDF الوصل، حالة الطلب.
- صفحة التواصل والدعم (الاسم، اللقب، المؤسسة، الولاية، البلدية، العنوان، الهاتف، البريد) مع إرسال تلقائي إلى isaacdiaf2@gmail.com.

### المرحلة 2 — تفعيل Lovable Cloud (قاعدة البيانات والحسابات)
- تفعيل الخدمة السحابية: قاعدة بيانات + مصادقة + تخزين الملفات.
- الجداول: institutions, profiles, user_roles, subscriptions, payments, classes, subjects, teacher_assignments, students, lessons, files, exams, questions, options, attempts, results, homeworks, announcements, schedules, attendance, notifications, activity_logs, contracts.
- عزل كل مؤسسة عن الأخرى (Multi-Tenant) عبر سياسات أمان صارمة على مستوى الصفوف.
- الأدوار في جدول منفصل: platform_admin / institution_admin / teacher / student.
- منع تكرار البريد أو رقم الهاتف، إلزامية البريد والهاتف، منع فتح أكثر من حساب مؤسسة لنفس المستخدم.
- تسجيل الدخول، استرجاع الحساب، وتغيير كلمة المرور برمز داخل المنصة.

### المرحلة 3 — لوحة مدير المنصة
- إحصائيات: إجمالي المؤسسات، النشطة، المنتهية، طلبات الدفع الجديدة، إيرادات السنة.
- إدارة المؤسسات (قبول/رفض/تعليق)، إدارة المدفوعات مع عرض الوصل وأزرار قبول/رفض/إيقاف، التفعيل المباشر بعد الموافقة اليدوية، رموز التفعيل (استعمال واحد فقط)، إدارة الباقات والدعم.

### المرحلة 4 — لوحة مدير المؤسسة
- شعار وألوان المؤسسة، إدارة الأساتذة والطلاب (إضافة/حذف/دعوة)، الأقسام والشعب والتخصصات، المواد وربطها بالأساتذة، الجداول، الحضور والغياب، النتائج، الإعلانات، الاشتراك والتجديد، تحويل الطلاب بين المؤسسات.

### المرحلة 5 — لوحة الأستاذ
الرئيسية، موادي، الدروس (إنشاء درس: عنوان، وصف، نص، PDF، فيديو، صور)، الملفات، الاختبارات (اختيار من متعدد، صح/خطأ، إجابة قصيرة) مع تصحيح آلي وتوقيت وحفظ المحاولات، النتائج حسب القسم والشعبة والتخصص، الجدول، الإعلانات، الإعدادات — مع منع رؤية بيانات خارج أقسامه.

### المرحلة 6 — لوحة الطالب
الرئيسية، موادي، دروسي (مع تحديد الدرس كمكتمل)، الملفات (عرض وتحميل)، الاختبارات، نتائجي، الجدول، الإعلانات، الإعدادات — قراءة فقط لما يخصه.

### المرحلة 7 — الإضافات المتقدمة
- العقود الرقمية بين مدير المنصة ومدير المؤسسة مع الإمضاء بالإصبع/الفأرة وكود QR مكان الختم ونسخة لكل طرف.
- تنبيهات انتهاء الاشتراك (30 يومًا / 7 أيام) وتجميد الحساب دون حذف البيانات، ومسار التجديد.
- الرسائل بين الإدارة والأستاذ والطالب، الإشعارات الفورية، الأسئلة تحت كل درس.
- التقارير الذكية، سجل العمليات، الفواتير والتقارير المالية.
- المصادقة الثنائية عبر واتساب/رسالة نصية، وتحميل الدروس للعمل دون اتصال مع المزامنة (تتطلب خدمات خارجية سأطلب مفاتيحها في وقتها).

### ملاحظات تقنية
- التخزين والمصادقة عبر Lovable Cloud؛ الملفات (PDF/فيديو/صور/وصولات الدفع) في تخزين محمي بسياسات وصول لكل مؤسسة.
- إرسال البريد يتطلب نطاقًا خاصًا بك لاحقًا؛ في البداية تُحفظ رسائل الدعم في قاعدة البيانات وتُعرض في لوحة مدير المنصة إضافة إلى الإرسال للبريد المذكور.
- المصادقة الثنائية عبر واتساب/SMS تحتاج مزود خارجي (مثل Twilio) ومفتاح API منك.
